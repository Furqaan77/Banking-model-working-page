# Three Applicants, One Rulebook

An animated walkthrough of how the AI Risk Score Card decides a personal loan at a fictional UAE bank.

- `index.html` is the whole site: one self-contained page, no build step.
- Deploy on Netlify: "Add new site" → "Import an existing project" → pick this repo. Leave the build command empty; the publish directory is the repo root (set in `netlify.toml`).
- Controls: Play/Pause, Back, Next, Restart, the arrow keys and the space bar. Add `#s=3` to the URL to open at a given scene.

The bank, the customers and the bank's own rules are examples. The CBUAE limits (Regulation 29/2011) are real and should be verified again before client use.
